Welcome to AVL-JTAG's Documentation
===================================

What is AVL?
------------

**AVL** is the Apheleia Verification Library.

For full details see `AVL Documentation <https://avl-core.readthedocs.io/en/latest/>`_.

What is JTAG?
-------------

**JTAG** is the IEEE 1149.1 Test Access Port and Boundary-Scan Architecture, widely used for debug, \
test and programming of devices.

What is OpenOCD?
----------------

`OpenOCD <https://openocd.org/pages/about.html>`_ is the Open On-Chip Debugger. It provides JTAG scan \
primitives, debug support for many processor architectures, flash programming and a Tcl scripting interface.

Why Use AVL-JTAG?
-----------------

Most JTAG verification components re-implement the TAP protocol and scan primitives in the testbench. \
AVL-JTAG instead drives the bus from OpenOCD itself, using its ``remote_bitbang`` adapter. This means:

- Sequences are written as OpenOCD Tcl commands - the same commands used in the lab
- Existing OpenOCD configuration and scripts (TAP definitions, targets, debug / flash operations) can be re-used in simulation
- The pin level protocol is generated by production quality software rather than a testbench model

The monitor, coverage, bandwidth and trace components are independent of OpenOCD and observe the pins directly.
